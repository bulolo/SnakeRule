# AI 决策扩展预研

> 状态：暂缓接入。当前 SnakeRule 不调用 Jev 或其他 AI 决策 API。
> 本文记录未来评估 AI 条件服务时需要回答的问题，不描述已有产品能力。

## 当前状态

配置结构和 `backend/.env.example` 保留了 Jev 参数占位，但当前求值器没有读取它们，也没有 AI HTTP 客户端、Fact Resolver、缓存或降级实现。规则中写入 `jev.*` 只会被当作普通 fact 路径处理。

因此 README、管理端和 API 文档不应把 AI 决策描述为当前可用功能。

## 重新评估前的要求

1. 确认实际服务供应方、官方 API 文档、数据处理条款和可用区域。
2. 确认发送到外部服务的 facts 是否包含个人信息、商业敏感信息或受监管数据。
3. 定义请求超时、重试上限、费用限制、服务故障时的确定性降级行为。
4. 将 AI 输出版本、置信度、输入摘要和规则决策关联，避免将随机输出伪装为确定性结果。
5. 为管理端配置添加密钥保护和最小权限，不允许将服务端密钥发送到浏览器。
6. 添加离线测试样本、漂移评估和审计记录后，再决定是否进入规则求值链。

## 候选接口边界

若未来确有需求，可先定义独立的 Fact Resolver 接口，在条件求值前把外部结果显式写入事实上下文。解析失败应返回可识别错误或使用经产品确认的显式默认值；不要在比较运算符中隐式发起网络请求。

在确认供应方和数据策略前，不固定产品名称、模型名称、延迟承诺、概率质量或兼容协议。
