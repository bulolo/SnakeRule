# SnakeRule 开发路线图

本文记录当前实现与后续工作。已完成项表示基础功能已进入代码，不代表已经达到高可用或完整的生产运维能力。当前版本以仓库根目录 `VERSION` 为准。

## 当前已具备

- Go HTTP API、健康检查、就绪检查、版本信息和统一 JSON 响应体。
- 超级管理员、组织管理员、项目管理员与项目成员的基础账号和授权管理。
- PostgreSQL 持久化与 Goose 数据库版本迁移；新数据库通过初始迁移建立结构。
- 组织、项目和项目范围规则集管理；支持空项目与电商订单演示项目。
- 项目 API Key 与 JWT 凭据管理、撤销及求值鉴权；支持 API Key 过期、平台签发 JWT 和项目自签 HS256 JWT。
- 规则集画布与 JSON 编辑、条件校验、已保存规则求值及草稿试运行。
- 调用日志、站内通知、组织告警渠道和项目规则命中通知。
- OpenAPI 契约、生成的管理端 TypeScript SDK、开发与生产 Compose、Helm Chart 和 VitePress 文档。
- Pulse 产品授权状态、授权文件管理及授权有效时的运行状态上报。
- 规则求值单元测试、空 PostgreSQL Goose 迁移集成测试，以及 GitHub Actions 后端/前端/文档构建检查。
- PostgreSQL 备份与恢复操作说明；生产恢复演练仍需部署方实际执行并记录结果。

## 优先完善

1. [ ] **仓储并发安全**：当前每个仓储进程内缓存聚合并整组同步数据库表；单次同步使用事务，但多 API 副本间没有缓存一致性或冲突检测，可能互相覆盖。改为数据库主导的细粒度读写或加入明确的并发控制后，再开放多副本。
2. [ ] **生产恢复演练**：按[备份恢复手册](./operations/database-backup-restore.md)定期验证备份可恢复；在生产升级前确认恢复点、迁移检查和失败处理负责人。
3. [ ] **凭据观测与滥用防护**：补充 API Key 最后使用时间和凭据管理审计；在求值 API 对公网开放前，按项目或凭据增加限流。API Key 已支持过期与撤销；轮换可先通过新旧 Key 短时并行、验证新 Key 后撤销旧 Key 的流程完成。
4. [ ] **告警投递可靠性**：规则命中通知目前由后台 goroutine 直接发送，失败只写服务日志。若告警属于生产关键路径，增加持久化队列、有限重试、幂等和投递状态查询。
5. [ ] **JWT 使用约定**：平台签发 JWT 已验证 issuer 与过期时间；项目自签 JWT 通过 `kid` 绑定项目凭据并校验过期时间，删除凭据可撤销。补充签名密钥轮换操作指南；仅当 Token 跨服务复用或授权范围扩展时再加入 audience 校验。
6. [ ] **扩大测试覆盖**：为认证、组织/项目权限边界、仓储并发和通知投递补充单元及 PostgreSQL 集成测试；将关键工作流设为合并保护检查。

## 规则生命周期与运行观测

- [ ] **规则集版本与发布**：先明确草稿和已发布版本的 API/界面边界；每次发布保存不可变快照、发布人和时间，在线求值只读取已发布快照。支持发布前校验、版本对比、回滚（以新版本重新发布旧快照）和变更审计。涉及独立版本表与迁移，禁止通过覆盖历史版本实现回滚。
- [ ] **决策记录**：为每次求值保留规则集版本、命中规则、结果、耗时、来源及请求/响应摘要；提供按时间、规则集、结果、来源和请求 ID 检索的分页接口。保留期限可按部署配置，清理任务分批执行并可观测；敏感字段继续遮蔽。
- [ ] **性能基线**：先提供可重复的负载场景和测试数据，记录并发量、吞吐、p50/p95/p99 延迟、错误率、CPU/内存与数据库连接数。分别测量纯求值和完整 API 链路，再依据结果决定索引、缓存和热更新，禁止没有基线就引入缓存复杂度。
- [ ] **条件画布**：保持 All/Any/Not 任意嵌套可视化编辑；操作符按事实类型分组并提供简短说明，编辑时校验必填字段、值类型和分组结构，保存前复用后端校验并定位错误节点。为操作符语义和嵌套边界补测试。
- [ ] **服务指标与告警**：增加真实采集的请求总量、错误率、延迟分位数、求值数量/耗时、数据库连接与迁移状态指标；暴露 Prometheus 可抓取端点，并提供最小告警规则和部署配置。管理端只展示采集所得指标；无采集数据时明确显示“暂无数据”，不展示推算值。

实施顺序与数据/API 设计见[规则生命周期与运行观测方案](./roadmap/rules-lifecycle-observability.md)。先交付发布快照与决策记录的后端契约，再接管理端；性能优化需等待基线结果。每个阶段都要包含数据库迁移、OpenAPI/SDK、单元与集成测试及升级说明。

## AI 与外部集成

- [ ] 确认模型供应方、数据处理边界、成本限制、超时和确定性降级策略，再接入 AI 决策。
- [ ] 定义 AI 输出与规则结果的版本、来源和审计关联，避免将模型输出误表示为确定性结果。
- [ ] 按实际集成需求评估 Go SDK、事件接入、流程节点和其他产品连接器。
- [ ] 仅在计算服务需要独立扩缩容时，评估拆分求值服务及引入消息或缓存基础设施。
