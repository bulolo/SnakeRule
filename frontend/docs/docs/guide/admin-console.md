# 管理工作台

登录后，侧栏提供「概览」和「项目」两个主入口。规则集属于项目，进入项目详情后可查看具体规则和规则集；右上角显示当前管理员和账号菜单，顶栏左侧的工作空间选择器切换当前会话使用的空间。

## 概览

概览按工作空间展示项目入口，不展示某个项目的规则统计。点击项目卡片进入项目内容。

此页展示的是当前工作空间中的配置统计，不是决策调用量、命中率或服务性能监控。

## 规则管理

项目详情是规则集的管理入口，直接列出项目内规则集及其规则，并支持搜索和删除。创建规则集通过弹窗填写名称后进入设计器；打开规则集进入设计器，返回后回到原项目详情。项目列表与项目详情不再重复提供规则集管理页面。数据通过 API 保存到当前进程的内存仓储。

设计页面包含画布和 JSON 两种视图：

- **画布**：维护规则、条件和声明动作。条件构建器编辑当前支持的基础条件；复杂组合可以在 JSON 视图中调整。
- **JSON**：查看和编辑完整规则集定义。保存前会由服务端校验规则 ID、名称、条件结构和操作符。
- **决策试运行**：提交 facts 后显示匹配结果。未保存的规则草稿也可试运行，草稿评估不会写回规则仓储。

规则按优先级从高到低评估，返回所有命中的启用规则。`tag`、`log` 等 action 当前只是结果数据，不会调用外部服务或写执行日志。

## 工作空间

顶栏选择器切换当前登录会话的空间。平台设置中的「工作空间」页可创建、编辑和删除工作空间：

- slug 由小写字母、数字、连字符和下划线组成；留空时服务端生成。
- 默认空间的 slug 固定为 `default`，默认空间不能删除。
- 当前空间不能直接删除；请先在顶栏切换到其他空间。
- 删除空间会连同该空间中的规则集一起删除。

工作空间与规则集目前都保存在 API 进程内存中，后端重启后会重置为默认空间和演示规则。

## 项目

工作空间下可以创建多个项目。项目列表以卡片展示项目，进入卡片后管理项目规则、资料、API Key 和告警策略。鉴权与告警配置从项目详情右上角图标打开弹窗；新建项目、编辑项目和删除项目都使用弹窗。项目页支持空项目或电商订单风控演示项目。演示项目会创建 `order-risk` 规则集，包含黑名单、大额新客审核和 VIP 标记规则。

项目 API Key 可在项目页创建和撤销。Key 创建时显示一次，之后只显示前缀；目前仅可调用已保存规则集的求值 API，使用 `X-API-Key` 请求头。开发版将 Key 摘要保存在内存，重启后会清除；当前未提供过期时间和最后使用时间。

项目告警策略选择系统设置里启用的企业微信、钉钉、飞书或自定义 Webhook 渠道，可指定命中的规则。已保存规则求值命中后，服务会异步发送通知；草稿试运行不会发送告警。投递失败写入服务日志，目前没有管理端投递记录。

## 平台设置

通过右上角平台设置入口可查看：

- **概览**：产品版本、管理员和 API 连通状态。
- **系统信息**：服务版本、授权状态和实例 ID；可刷新、上传、替换或清除授权文件。
- **工作空间**：工作空间的增删改查。
- **全局配置**：当前规则求值、存储和会话方式的只读摘要。

授权文件经服务端 Pulse Agent 校验后加密保存。当前规则功能没有基于授权状态的门禁，页面中的授权信息仅显示授权状态。

## 系统设置

系统设置提供通用信息、告警渠道和账号安全信息。告警渠道支持企业微信机器人、钉钉机器人、飞书机器人和自定义 HTTP(S) Webhook，并可发送测试通知。钉钉和飞书支持机器人签名密钥；自定义 Webhook 支持 Bearer 密钥；企业微信使用机器人地址中的 key。密钥不会由读取接口返回，编辑时留空可保留现有密钥。

渠道配置保存在 API 进程内存中，重启后会重置。测试通知用于验证配置的目标地址和凭据。

## 退出登录

打开右上角账号菜单，选择「退出登录」。服务端撤销会话并清除 HttpOnly Cookie，管理端随后返回登录页。会话有效期由 `AUTH_SESSION_TTL` 配置，默认值为 24 小时；当前会话保存在服务进程内存中，重启 API 后会失效。
