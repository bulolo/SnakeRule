# 管理工作台

登录后，侧栏提供「概览」和「项目」两个主入口。规则集属于项目，进入项目详情后可查看具体规则和规则集；右上角显示当前管理员和账号菜单，顶栏左侧的组织选择器切换当前会话使用的组织。

## 概览

概览按 OwlAPI 的信息层次组织为指标卡、调用趋势和最近动态：显示近 7 天的求值调用、命中与失败统计，趋势统计包含管理端、设计器模拟和项目 API 来源。右侧“调用日志”展示最近记录；点击更多图标可打开分页列表，并查看单条记录的概览、请求和响应内容。

## 规则管理

项目详情是规则集的管理入口，直接列出项目内规则集及其规则，并支持搜索和删除。创建规则集通过弹窗填写名称后进入设计器；打开规则集进入设计器，返回后回到原项目详情。项目列表与项目详情不再重复提供规则集管理页面。数据通过 API 保存到 PostgreSQL。

设计页面包含画布和 JSON 两种视图：

- **画布**：维护规则、条件和声明动作。条件构建器编辑当前支持的基础条件；复杂组合可以在 JSON 视图中调整。
- **JSON**：查看和编辑完整规则集定义。保存前会由服务端校验规则 ID、名称、条件结构和操作符。
- **决策试运行**：提交 facts 后显示匹配结果。未保存的规则草稿也可试运行，草稿评估不会写回规则仓储。

规则按优先级从高到低评估，返回所有命中的启用规则。`tag`、`log` 等 action 当前只是结果数据，不会调用外部服务或写执行日志。

## 组织

顶栏选择器切换当前登录会话的组织。平台设置中的「组织」页可创建、编辑和删除组织：

- slug 由小写字母、数字、连字符和下划线组成；留空时服务端生成。
- 默认组织的 slug 固定为 `default`，默认组织不能删除。
- 当前组织不能直接删除；请先在顶栏切换到其他组织。
- 删除组织会连同其中的项目、规则集和相关配置一起删除。



## 项目

组织下可以创建多个项目。项目列表以卡片展示项目，进入卡片后管理项目规则、资料、API Key 和告警策略。鉴权与告警配置从项目详情右上角图标打开弹窗；新建项目、编辑项目和删除项目都使用弹窗。项目页支持空项目或电商订单风控演示项目。演示项目会创建 `order-risk` 规则集，包含黑名单、大额新客审核和 VIP 标记规则。

项目 API Key 与 JWT 可在项目页创建和撤销。凭据创建时显示一次；API Key 后续只显示前缀，使用 `X-API-Key` 请求头调用已保存规则集的求值 API。JWT 支持平台签发访问 Token（默认 30 天，可设过期时间）和项目自签两种方式；自签模式生成项目级 HS256 密钥，JWT Header 需携带 `kid`（凭据 ID），Payload 需有 `exp`。密钥仅创建时显示，服务端加密保存。

项目告警策略选择当前组织中启用的企业微信、钉钉、飞书或自定义 Webhook 渠道，可指定命中的规则。已保存规则求值命中后，服务会异步发送通知；草稿试运行不会发送告警。投递失败写入服务日志，目前没有管理端投递记录。

## 平台设置

平台设置入口仅超级管理员可见，包含：

- **系统信息**：服务版本、授权状态和实例 ID；可刷新、上传、替换或清除授权文件。
- **组织管理**：组织的增删改查；创建时可指定初始组织管理员。
- **平台品牌**：配置产品名称、标语与 Logo 地址，并应用到登录页和管理端。

授权文件经服务端 Pulse Agent 校验后加密保存。当前规则功能没有基于授权状态的门禁，页面中的授权信息仅显示授权状态。

## 组织设置

组织设置提供组织信息、用户管理和告警渠道。组织管理员可管理当前组织的账号及通知渠道，不能创建超级管理员。新建组织时，平台管理员可指定现有账号作为初始组织管理员。项目详情的“成员”页签可为单个项目分配项目管理员或项目成员；组织管理员默认可以管理该组织内全部项目。告警渠道支持企业微信机器人、钉钉机器人、飞书机器人和自定义 HTTP(S) Webhook，并可发送测试通知。钉钉和飞书支持机器人签名密钥；自定义 Webhook 支持 Bearer 密钥；企业微信使用机器人地址中的 key。密钥不会由读取接口返回，编辑时留空可保留现有密钥。

测试通知用于验证渠道配置。

## 退出登录

打开右上角账号菜单，选择「退出登录」。服务端撤销会话并清除 HttpOnly Cookie，管理端随后返回登录页。会话有效期默认 24 小时，退出登录后会立即失效。
