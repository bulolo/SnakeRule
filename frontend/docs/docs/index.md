## 当前版本

SnakeRule 当前管理端包含概览、项目、平台设置和组织设置。平台设置仅超级管理员可访问，包含系统信息、组织管理和平台品牌配置；组织设置管理当前组织的用户与告警渠道。规则能力包括规则集增删改查、拖拽画布、JSON 编辑、已保存规则执行和草稿试运行。

规则动作作为决策结果返回。

开始前请查看[快速开始](/guide/quick-start)，了解本地启动步骤和访问地址；[管理工作台栏目说明](/guide/admin-console)介绍各入口的用途与当前边界。
